# DiagNova
Modular AI-powered medical image analysis platform for disease classification using Machine Learning and Deep Learning.

## Objective
Build a unified platform for analyzing multiple medical imaging modalities using Machine Learning and Deep Learning.

## Planned Modules
- Chest X-ray Classification
- Brain MRI Classification
- Skin Lesion Classification
- Streamlit Web Application
- Model Evaluation Dashboard

## Tech Stack
- Python
- PyTorch
- OpenCV
- Streamlit
- Scikit-learn
- Pandas
- NumPy
