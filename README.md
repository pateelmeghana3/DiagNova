# 🩺 DiagNova

An AI-powered Chest X-ray Pneumonia Detection System built using Deep Learning. DiagNova classifies chest X-ray images as **Normal** or **Pneumonia** using a custom Convolutional Neural Network (CNN). The project includes image preprocessing, model training, evaluation, and a Streamlit-based web application for predictions.

---

## 🚀 Features

- 🩻 Chest X-ray Pneumonia Detection
- 🧠 Custom CNN Model using PyTorch
- 🖼️ Image Preprocessing & Data Augmentation
- 📊 Model Training & Evaluation
- 🌐 Streamlit Web Application
- 💾 Model Saving & Loading

## ⚙️ Installation

```bash
git clone <repository-url>
cd DiagNova
pip install -r requirements.txt
```

---

## ▶️ Run the Project

Train the model:

```bash
python -m src.training.train
```

Launch the Streamlit app:

```bash
streamlit run streamlit_app/app.py
```
